**BREAKING:** `AsyncMemoryClient.delete()` now requires keyword-only `confirm` (must equal the project ID) sent as the DELETE body; `OZChatMessageHistory.clear()/aclear()` without `confirm` only clear the local cache with a `DeprecationWarning` — pass `confirm` for the server wipe. `delete_memory` MCP tool requires `confirm`. Transport: `204`/empty-2xx on body-expecting methods and non-JSON 2xx now raise `OpenZyncError` (no more `None`/`{"_raw": ...}` fallbacks; `None` is returned only for `DELETE` + `204`); `POST` retries only with an `Idempotency-Key` header, otherwise fails fast; sync clients raise `OpenZyncError` (not `RuntimeError`) inside a running loop. `AsyncFactsClient.add()` accepts an optional `idempotency_key` enabling safe retry.
