**BREAKING:** response models overhauled to match core's real contracts — `ProjectMemberResponse.project_id` was removed (core never returns it; the project is resolved from the API key) and `ProjectMemberResponse.created_at` is now a `datetime` instead of a `str`. Eight response models across the facts, memory, observation, schema, session, user, project and graph domains gained previously-missing required fields (e.g. `organization_id`, `project_id`, `superseded_count`, `pending_enrichment_count`) and typed `datetime` timestamps, so constructing them from partial/legacy dicts now raises `pydantic.ValidationError`. Parse API responses through the models rather than hand-building them.
