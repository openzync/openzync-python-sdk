Map every transport-level failure onto the SDK error taxonomy: `httpx.TransportError` (connection refused, DNS failure, protocol error, pool timeout) now raises `openzync._errors.TransportError` instead of escaping as a raw `httpx` exception, and a timeout raises the new `RequestTimeoutError` (a `TransportError` subclass). `TransportError` means "the API never answered"; `ExternalServiceError` still means "the API answered 502".
