**BREAKING:** client-side guards that raised `ValueError` now raise typed errors inside the `OpenZyncError` taxonomy, so `except ValueError` no longer catches them — catch `OpenZyncError` (or the specific subclass) instead. `AsyncHTTPTransport.resolve_project_id()` raises `AuthorizationError` when the API key has no project scope; empty `name`/`sample_text`, an unknown `schema_type`, and ambiguous `subject_id`/`subject_ids` raise `ValidationError`.
